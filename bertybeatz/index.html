How it works

  1. The Menu button at the top left opens the menu.
  2. Tap a square to turn a sound on. Tap again to turn it off.
  3. Press Play. The moving column is the beat walking across the grid.
  4. Top rows are drums. Bottom rows are notes that always fit the key.
  5. Look chips change the pictures — Bars, Kaleidoscope, Clouds, Stars, Code. Same beat, different lights. Mute is OK.
  6. Pass copies a code — no names — so the next Chromebook can load the same beat.

Space bar plays and stops. Keys 1–5 switch Looks. Tap a row name to hear that sound. Title only, never a student name.
