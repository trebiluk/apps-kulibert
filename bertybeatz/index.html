How it works

  1. Tap a square to turn a sound on. Tap again to turn it off.
  2. Press Play. The moving column is the beat walking across the grid.
  3. Top rows are drums. Bottom rows are notes that always fit the key.
  4. Pass copies a code — no names — so the next Chromebook can load the same beat.

Space bar plays and stops. Tap a row name to hear that sound. Title only, never a student name.
