# Sprocket

Classroom 3D-print helper for Bambu Lab printers.

**Version:** 1.5.0  
**Live app:** https://apps.kulibert.net/sprocket/index.html  
Data stays in the browser (`localStorage` key `printkit-v2`).

## What is in this build
- Convert (mm/in, temp, flow, strength, class clock, rough time)
- Stock (spools, supplies, AMS map, dry flags, quick subtract)
- Timers (print / cool / glue / dry + pause / +5 min)
- Help (official Bambu wiki links)
- More (queue, fail log, printer care, backup/restore, teacher PIN)

No unofficial Studio impersonation. No live printer control in Phase 1.

Open `Sprocket.html` for the full single-file app. Chromebooks: Chrome, hard refresh after an update.
