# Drawin' stuff
Kulibert classroom paint app (Photopea / GIMP / Kleki-style) — DS 0.2.0.
Built on Klecks by bitbof (MIT) — https://github.com/bitbof/klecks. Original license in LICENSE is kept.
The vector studio is the sibling folder ../vector (Paper.js and opentype.js, MIT). This paint snapshot did not change.
Changelog:
- 2026-09-27 DS 0.2.0 — vector studio on the same door (pen, nodes, booleans, type, SVG). Paint moved to /drawin/paint/ so the old service worker cannot swallow it.
- 2026-09-24 DS 0.1.0 — first door: brushes, layers, filters, selection, text, PSD import/export, local save. Runs in the browser, no account.
