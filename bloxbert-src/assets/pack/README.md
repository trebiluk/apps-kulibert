# Bertopia asset pack (branch `bertopia-assets`)

One coherent style for Bertopia through 2.6.x and beyond. Rebuild everything from scripts; never hand-edit outputs.

```
KENNEY_VOXEL=/path/to/kenney_voxel-pack KENNEY_AUDIO=/path/to/kenney-audio-dir \
python3 tools/gen_pack.py && python3 tools/gen_icons.py && python3 tools/gen_sfx.py && python3 tools/check_pack.py
```
(The Kenney zips are not in the repo. Download them from the URLs in MANIFEST.csv; their sha256 values are in `licenses/SOURCE-ZIPS.sha256`.)

## What is here
| Path | What |
|---|---|
| `registry.json` | Data-driven registry: blocks (ids 1–31 = live 2.5.42, frozen; 32+ proposed in milestone order), items, sprites, biomes, elements, furniture palette. Each entry carries `milestone`, `availableFrom` (locked-tile rule, WORLD-1 §6), `handS`, and `dex` text. |
| `atlas/terrain.png` + `.json` | Opaque cube faces as a 32 px vertical strip (noa texture array). **Indices 0–20 match live `bloxbert-src/assets/atlas.json`**, so it drops straight in. It has 115 layers and the cap is 256. |
| `atlas/alpha.png` + `.json` | See-through cubes, cross plants, flat decor (glass, leaves, water, bushes, lights…). |
| `atlas/items.png` + `.json` | A 16-column grid of item icons, model-block icons (`block:<key>`) and furniture palette variants (`block:chair@teal`). |
| `textures/{blocks,items,sprites,minimap}/` | The individual PNGs that the atlases are built from. |
| `icons/ui/*.svg` | 68 HUD and panel icons built to RULE-icons: 24 viewBox, stroke 2, round caps, `currentColor`, `aria-hidden`. **Every icon must have a visible label next to it inside a 44 px target.** |
| `sfx/`, `music/` | `.ogg` and `.mp3` files: Kenney CC0 picks (transcoded and loudness-normalised) plus synth SFX and C4 instrument samples. Each sound is paired with a visual in the game. |
| `dex/bertodex-en.json` | Bertodex "What it is" lines. **DRAFT: Curriculum Bot checks them.** Build fills the other 7 languages per brief. |
| `MANIFEST.csv` | One row per asset: source URL, license as stated on the source page, author, made_by (`sourced`, `sourced-derived`, `generated`, `built`, `planned`), and sha256. `planned` rows are later-stage assets that are **not drawn yet**. |
| `licenses/` | Kenney License.txt files (CC0) and the source zip hashes. |

## Licence rules
- Third-party content comes only from Kenney packs whose page and bundled License.txt both say **CC0**. Nothing is guessed. Poly Haven and OpenGameArt were not needed: Poly Haven's photo-real style doesn't match, and no OpenGameArt file was used.
- Generated content is marked "Project-original (generated by script; owner trebiluk)". No licence is granted on the owner's behalf.
- There are no brand logos and no names or textures from other block games. `check_pack.py` blocks a list of forbidden words.

## Style rules (enforced in `check_pack.py`)
- 32×32 tiles, flat colours, 2×2 pixel clusters, and a 1 px dark outline on items and sprites.
- Every ore has a different **shape**, not just a different colour (WORLD-1 §7): coal is angular chunks, iron round dots, copper streaks, zinc flakes, tin squares, quartz spikes, silver thin lines, gold a wiggly vein, glow moss halo dots, ilmenite dark squares, platinum rimmed flecks, and graphite stacked flakes.
- Glare-safe: no block texture contains a pure #FFFFFF pixel. The brightest colour allowed is snow #EEF3F7 (WORLD-2 §4).
- Machines share one family look: a steel frame, rivets, and an accent stripe whose colour shows the family (power amber, logistics teal, network purple, craft orange, fun pink, music green, town wood).
- Model blocks such as levers, lanterns and tubes use **placeholder** item-style icons until their meshes are built. Their `block:` icon rows are marked "placeholder shape".
