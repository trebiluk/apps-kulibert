Teacher notes · BB 0.14.1

Classroom physics shop for Solvay Middle School Technology Education. XP and shop rank stay on this Chromebook — not a gradebook, no names. Lean machines (fewer parts than par) earn more. How-to is four animated beats. Phones: landscape. Menu holds Save / cart / teacher. Not affiliated with Northway Games or Fantastic Contraption.

Site Editor

Shop Floor, Drop Zone, slabs, and extra crates live only in Site Editor. Roll Out and the other challenges lock the site so a pair cannot drag the Drop Zone closer. Assign Site Editor when the job is to design a course. Save a title only — no names.

After a test

Stop writes one line in the status bar: parked, stalled, fell, overshot, or missed. The orange trail stays as a dashed ghost so the pair can talk about the process path. Observer gets a yellow ring on the crate during Play. Intern debug: add ?debug=1 or tap backtick — chip, fps, last readout. No names.

Class heat and pair chip

Heat on the HUD is how many crates got parked this period — a class count, not a roster. Chromebooks on this shop share the number. It is not a grade, not TechCash, not desk XP.

The stage chip is Builder / Observer. Builder places parts. Observer watches the crate (trail, Slow, Drop Zone). Swap without typing a name. Tools stay unlocked so a pair can share one cart.

Start of period: Menu → New period. Heat goes to 0 parked on every cart that hears it.

Projector shows the machine and the heat number. Never a kid rank list. Phone landscape still keeps course + Play + Stop + Menu; rank stays in Menu.

Assign Measure (graph paper)

Regular shop has no grid. When you want counting and units, assign Measure from the course list, or send:

apps.kulibert.net/bertybots/?course=measure

1 square = 1 unit. Tape tool: two clicks on a grid line. Three logs: Shop Floor width (8), Drop Zone width (4), gap between them (8). Completing it awards local XP. No names. They can still build after the logs.

Say this out loud

  1. Ask the job: park the Bot Core crate in the Drop Zone.
  2. Imagine parts as a system, not as toys.
  3. Plan on the Shop Floor. Builder places. Observer watches the crate.
  4. Create, then Test (Play). Stop restores the shop.
  5. Improve one thing. Save a course title only — no names.

Tutorial (first four courses)

How to shop is four beats, then Try Roll Out. Guide rail stays on unless they tap Guide off. Course coaches:

CourseWhat the guide teaches
Roll OutStraight process path. Starter cart is legal. Floor pusher.
Up the CurbOutput is up. A pusher is not a ramp. Height is a constraint.
Mind the PitMissing process path. Falling is a failed output.
The WallBlocked process. More Drive into a wall is still a wall.

High Shelf, Around the Bend, Pair of Crates keep a shorter systems line. Starter cart is not the answer on walls or shelves.

Shop handling

  • Drag a Drive/Roller from the toolbar onto a hub. Orange ring = it will join.
  • Grab any part to move it. It snaps to the nearest hub on release.
  • Steel / Ghost: press on a node and drag the bar. A tap is ignored.
  • Drive needs a Steel bar on the hub (center), not only the rim.
  • Ghost Bar ignores the machine, hits the world and the crate.
  • Stop always restores the shop. Slow-mo is for pointing at a fail.
  • Files: .bertybots.json — level title only, no names.

Standards snapshot

NYS MST Standard 5 — students apply a complete design process (identify the need, generate options, model, test, iterate, communicate) and treat the machine as a technological system.

ITEEA STL — Standard 2 (systems: input, process, output, feedback, constraints, subsystems). Standards 8–11 (attributes of design, engineering design, troubleshooting / experiment, apply the design process).

CDOS — pair roles, file hygiene, talking about a fail with shop words (hub, constraint, payload, feedback).

CTE / careers — test technician, mechanical designer, automation. Compare Shop Floor → Play → Improve to a real prototype loop.

5-day sketch

  1. Day 1 — How to shop + Roll Out. Exit ticket (oral): name input, process, output.
  2. Day 2 — Up the Curb. Why the starter cart fails. One improvement logged out loud.
  3. Day 3 — Mind the Pit. Observer calls the fail in Slow.
  4. Day 4 — The Wall or student-authored course (Level layer).
  5. Day 5 — Save file (title only) + 3-sentence “how this machine is a system.” Paper or talk. Not in the JSON.
