What this game is

Berty's Botz is a construction shop. You design a machine. Gravity and the Drive wheels are the forces. The job is to park the Bot Core crate in the Drop Zone.

Settings

Language

This machine is a system

  1. Input — gravity, Drive-R / Drive-L torque, starting pose of the crate
  2. Process — your machine: Drive, Roller, Steel, Ghost
  3. Output — crate motion; win = every Bot Core inside the Drop Zone for one second
  4. Feedback — orange trail, Slow, In the zone, Stop restores the shop

Constraints: 48 parts, Shop Floor, slabs, period time.
