## 2. Answers to the draft's §3 questions
1. **Exo-Suit glide:** yes, hold Jump in the air = Move (Gravity Hat pattern). Not a new action.
2. **Mining Beam:** a scoped Mine: hold Mine, straight line, up to 6 blocks, with a preview line on the target. Never hits players, never works inside someone else's claim. Not a new action.
3. **Glideway pods:** confirmed. Use = board. Move or Jump gets you off only when the pod is stopped; while moving, Jump shows a "Stop at next station" chip and the pod stops there.
4. **Quarry / Filler / Scanner marking:** same corner-tap pattern as Publish (Place 2 Survey Markers), so kids learn it once. No new tool action.
5. **Terminal Request:** yes, a Request button inside the Open panel is enough.
6. **Seed Lab:** passes if the wording stays "traits pass down" (Curriculum owns the line).
7. **Chunk Keeper:** cut (above).
